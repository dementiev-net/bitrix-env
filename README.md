# Universal Bitrix Docker Environment (PHP 8.4)

Чистый и оптимизированный Docker-стек для разработки на 1С-Битрикс любой редакции. 
Базируется на официальных образах `bitrix24/ (quay.io)`, максимально приближенных к Bitrix Virtual Appliance.

## ✨ Особенности
* **PHP 8.4** (FPM) — современный стек с предустановленными расширениями для Битрикс.
* **Nginx** — настроенные конфигурации (вместо .htaccess), включая правила для ЧПУ и безопасности.
* **Percona Server 8.0** — оптимизированная база данных.
* **Memcached** — для быстрого кеширования "из коробки".
* **Cron** — отдельный контейнер для выполнения агентов Битрикс на системном уровне.
* **Универсальность** — пустая структура, готовая к установке любой редакции (Старт, Стандарт, Малый Бизнес, Бизнес).

## 🛠 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/dementiev-net/bitrix-env.git
   cd bitrix-env
2. **Подготовьте файлы Битрикса:**
   Положите скрипт `bitrix_setup.php` или распакованный дистрибутив в папку `www/`.
3. **Запустите окружение:**
   ```bash
   docker-compose up -d
   
   ```
4. **Установка:**
   Откройте в браузере `http://localhost/bitrix_setup.php`.

## 📁 Структура проекта

* `/www` — корень сайта (DocumentRoot).
* `/confs` — конфигурации PHP и Nginx (правки вносятся здесь).
* `/db_data` — файлы базы данных (игнорируются Git).
* `/bx_temp` — временные файлы Битрикс.
* `/logs` — логи сервисов.

## 📝 Важные нюансы

### Права доступа

Если установщик Битрикс не может создать файлы, выполните команду:

```bash
docker-compose exec php chown -R www-data:www-data /opt/www /opt/.bx_temp

```

### Настройка .htaccess

Поскольку используется Nginx, файлы `.htaccess` игнорируются. Все правила уже прописаны в `confs/nginx/conf.d/default.conf`.

### Агенты на Cron

После установки переведите агентов на cron. В контейнере `bx-cron` уже запущен нужный демон.
